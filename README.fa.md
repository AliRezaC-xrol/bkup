## معرفی

`bkup` به هر پنلی که تنظیم کنید وصل می‌شود، طبق زمان‌بندی شما از هر کدام
**بکاپ کامل** می‌گیرد و آن را به‌صورت فایل به چت یا کانال **تلگرام** شما
می‌فرستد. سرویس روی سرور خودتان به‌صورت systemd اجرا می‌شود — با سقف CPU و
RAM، ری‌استارت خودکار و راه‌اندازی مجدد بعد از ری‌بوت.

```
  3x-ui ────────┐
  HM Panel ─────┤   bkup از هر پنل فعال، طبق زمان‌بندی شما بکاپ کامل می‌گیرد
  PasarGuard ───┘
                                │
                                ▼
                      چت تلگرام شما  ← هر بکاپ به‌صورت فایل می‌رسد
```

هر پنل جدا تنظیم می‌شود: هر کدام را که استفاده می‌کنید فعال کنید و اتصالش را
با یک کلیک تست کنید. فاصله بکاپ بر حسب **ثانیه** است — از چند بکاپ در روز تا
یکی هر چند دقیقه، همان یک نصب کافی است.

## امکانات

- **3x-ui، HM Panel و PasarGuard یک‌جا** — هر پنل مستقل فعال می‌شود و دکمه تست خودش را دارد
- **ارسال به تلگرام** — هر بکاپ به‌صورت فایل در چت یا کانال شما می‌رسد؛ نیازی به دانلود دستی نیست
- **زمان‌بندی شما** — فاصله بر حسب ثانیه، پایدار بعد از ری‌بوت با سرویس systemd
- **پنل وب** — داشبورد، لاگ زنده و تاریخچه بکاپ با دانلود و حذف تک‌تک
- **منوی ترمینال** — `bkup` وضعیت، آدرس پنل، رمز، پورت، لاگ، آپدیت و حذف را بدون باز کردن پنل وب انجام می‌دهد
- **آپدیت همیشه آخرین نسخه** — نصب‌کننده و آپدیت‌کننده آخرین ریلیز گیت‌هاب را می‌گیرند، کد را با تگ تطبیق می‌دهند و هر چیز دیگری را رد می‌کنند؛ دیتابیس، تنظیمات و بکاپ‌های شما دست‌نخورده می‌مانند

## نصب

```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/AliRezaC-xrol/bkup/main/install.sh)
```

این دستور در صورت نبود Node.js 20 را نصب می‌کند، **آخرین نسخه** را دانلود و
تأیید می‌کند، برنامه را بیلد و سرویس را ثبت می‌کند و در پایان آدرس پنل و رمز
آن را نشان می‌دهد. اجرای دوباره روی همان سرور یعنی آپدیت درجا — با حفظ همه
تنظیمات و بکاپ‌ها.

## شروع سریع

| مرحله | کجا | چه کاری |
|---|---|---|
| **۱** | نصب‌کننده | انتخاب پورت (یا پورت تصادفی) و رمز پنل |
| **۲** | مرورگر | باز کردن `http://<server-ip>:<port>` و ورود با رمز |
| **۳** | **Settings** | اتصال 3x-ui / HM Panel / PasarGuard — زدن دکمه تست |
| **۴** | **Settings** | افزودن توکن بات تلگرام + آیدی چت — زدن دکمه تست |
| **۵** | **Settings** | تنظیم فاصله بکاپ و روشن کردن **Auto backup** |

## آپدیت

| از کجا | چطور |
|---|---|
| پنل وب | **System → Check for updates → Update** |
| ترمینال | `bkup` → **Update** |
| هر جا | اجرای مجدد دستور نصب |

نسخه‌ای که در پنل نمایش داده می‌شود در زمان بیلد از کد تزریق می‌شود؛ بعد از
آپدیت همیشه با چیزی که واقعاً اجرا می‌شود یکی است.

## منوی ترمینال

روی سرور `bkup` را اجرا کنید:

| گزینه | کاربرد |
|---|---|
| **Status** | وضعیت سرویس، نسخه نصب‌شده، وجود آپدیت |
| **Web panel URL** | نمایش آدرس و پورت پنل |
| **Password** | تغییر رمز پنل وب |
| **Port** | تغییر پورت پنل وب |
| **Logs** | مشاهده زنده لاگ سرویس |
| **Update** | نصب آخرین نسخه درجا، با حفظ دیتا |
| **Uninstall** | حذف سرویس و برنامه |

## مسیرهای سرور

| مسیر / دستور | کاربرد |
|---|---|
| `/opt/bkup` | پوشه برنامه |
| `/opt/bkup/.env` | پورت و مسیرها |
| `/opt/bkup/db/custom.db` | دیتابیس تنظیمات |
| `/opt/bkup/backups` | نسخه محلی بکاپ‌ها |
| `bkup` | دستور منوی ترمینال |
| `bkup.service` | سرویس systemd |
