## معرفی

bkup روی سرور شما به‌صورت سرویس systemd اجرا می‌شود، در بازهٔ تعیین‌شده از هر پنل
فعال یک بکاپ کامل می‌گیرد و فایل را به چت یا کانال تلگرام می‌فرستد. مصرف منابع
محدود است، در صورت توقف خودش دوباره بالا می‌آید و پس از ریبوت سرور ادامه می‌دهد.

برای هر پنل یک روش بکاپ وجود دارد: بکاپ کامل خودِ پنل، بایت‌به‌بایت و بدون تغییر.

| پنل | آنچه گرفته می‌شود |
|---|---|
| **3x-ui** | دیتابیس کامل خود پنل (`x-ui.db`) |
| **HM Panel** | آرشیو رسمی و کامل پنل (`backup_full_*`) |
| **PasarGuard** | تصویر کامل: کاربرها، هاست‌ها، نودها، کورها، گروه‌ها، تنظیمات و تمپلیت‌ها |
| **Rebecca** | خروجی کامل رسمی پنل |

## امکانات

- چهار پنل در یک نصب، هر کدام با فعال‌سازی و تست جداگانه
- در هر دوره از هر پنل فعال یک بکاپ کامل و بدون تغییر، و ارسال آن به تلگرام
- فاصلهٔ بکاپ بر حسب ثانیه، با حفظ شدن پس از ریبوت و نگهداری محلی جداگانه برای هر پنل
- بکاپ‌های بزرگ‌تر از محدودیت ۵۰ مگابایتی تلگرام به‌صورت پارت‌های شماره‌گذاری‌شدهٔ همان فایل ارسال می‌شوند
- پنل وب: داشبورد، لاگ زنده، تاریخچهٔ بکاپ با دانلود و حذف، جست‌وجوی نام فایل در ترکیب با فیلتر وضعیت
- بازسازی: ادغام پارت‌ها به فایل اصلی، از روی آپلود یا از بکاپ‌های ذخیره‌شده
- ریستور: انتقال بکاپ روی سرور دیگر از طریق SSH، با نمایش زندهٔ مراحل، لغو، تاریخچه و تلاش دوباره
- خروجی و ورودی فایل تنظیمات برای انتقال نصب به سرور دیگر
- تغییر رمز عبور و خروج از همهٔ دستگاه‌ها با یک دکمه
- حالت تاریک و نصب به‌صورت اپلیکیشن روی صفحهٔ اصلی گوشی (PWA)
- بروزرسانی درجا از پنل وب یا منوی ترمینال

## نصب

دبیان یا اوبونتو با دسترسی root و Node.js نسخهٔ ۲۰ (در صورت نبودن خودش نصب می‌کند):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/AliRezaC-xrol/bkup/main/install.sh)
```

نصب‌کننده آخرین ریلیز را می‌گیرد، بیلد می‌کند و سرویس `bkup` را ثبت می‌کند و در پایان
آدرس و رمز پنل را چاپ می‌کند. اجرای دوبارهٔ همین دستور نصب را درجا بروزرسانی می‌کند و
دیتابیس، بکاپ‌ها و تنظیمات باقی می‌مانند.

با داکر:

```bash
docker compose up -d --build      # پنل روی http://SERVER_IP:3999 و داده در ./data
```

## شروع سریع

| مرحله | کجا | کار |
|---|---|---|
| **۱** | نصب‌کننده | انتخاب پورت و رمز پنل وب |
| **۲** | مرورگر | باز کردن `http://<server-ip>:<port>` |
| **۳** | تنظیمات | اتصال پنل‌هایی که استفاده می‌کنید و زدن دکمهٔ تست هر کدام |
| **۴** | تنظیمات | وارد کردن توکن بات تلگرام و شناسهٔ چت و زدن دکمهٔ تست |
| **۵** | تنظیمات | تعیین فاصلهٔ بکاپ و روشن کردن بکاپ خودکار |

## بازسازی پارت ها

تلگرام در هر پیام حداکثر ۵۰ مگابایت می‌پذیرد، پس بکاپ‌های بزرگ‌تر به‌صورت پارت‌های
شماره‌گذاری‌شدهٔ همان فایل فرستاده می‌شوند. بخش **Reassemble** آن‌ها را به یک فایل
کامل برمی‌گرداند — آپلود پارت‌ها یا انتخاب مستقیم از بکاپ‌های ذخیره‌شده. ترتیب بر
اساس شماره تعیین می‌شود، شماره‌های تکراری پیش از ادغام تشخیص داده می‌شوند و فایل
نهایی پیش از ذخیره از نظر سلامت بررسی می‌شود. پارت‌های یک فایل زیر یک سرگروه با
نشان «موجود از کل» می‌آیند، دکمهٔ **افزودن همه** کل مجموعه را انتخاب می‌کند و
تاریخچه از حذف گروهی پشتیبانی می‌کند.

## ریستور بکاپ روی سرور

بخش **Restore** یک بکاپ را از طریق **SSH** روی سرور دیگر می‌نشاند. پنل را بکاپِ
انتخاب‌شده تعیین می‌کند: بکاپ 3x-ui فقط روی 3x-ui و به همین ترتیب HM Panel،
PasarGuard و Rebecca — بدون مهاجرت بین‌پنلی و بدون بازنویسی بایت‌های بکاپ. اگر پنل
روی سرور مقصد نباشد، ابتدا نصب می‌شود. قرارگیری بایت‌به‌بایت تأیید و اجرای واقعی پنل
بررسی می‌شود، و گواهی‌نامه‌های ارجاع‌شده در دیتابیس ریستورشده پیش از راه‌اندازی از
خود بکاپ بازسازی می‌شوند. مراحل زنده نمایش داده می‌شوند، در میانهٔ کار قابل لغو است
و نتیجهٔ هر ریستور با فیلتر، خروجی CSV و تلاش دوباره در تاریخچه می‌ماند.

## آپدیت

| از کجا | چطور |
|---|---|
| پنل وب | سیستم → بررسی بروزرسانی → نصب بروزرسانی |
| پنل وب | نصب مجدد، برای نصب دوبارهٔ همین نسخه |
| ترمینال | `bkup` → گزینهٔ Update |
| هر جا | اجرای دوبارهٔ دستور نصب |

آپدیت آخرین ریلیز را پیدا می‌کند، نسخهٔ کد را با تگ آن بررسی می‌کند و در صورت
ناهم‌خوانی بدون دست زدن به نصب فعلی متوقف می‌شود.

## منوی ترمینال

روی سرور دستور `bkup` را اجرا کنید:

| گزینه | کاربرد |
|---|---|
| **۱** | وضعیت: حالت سرویس، نسخه و آمار بکاپ‌ها |
| **۲** | آدرس و پورت پنل وب |
| **۳ · ۴** | تغییر رمز · تغییر پورت پنل وب |
| **۵** | لاگ زندهٔ سرویس |
| **۶ · ۷** | بررسی بروزرسانی · بروزرسانی |
| **۸ · ۹ · ۱۰** | روشن · خاموش · ری‌استارت سرویس |
| **۱۱** | حذف سرویس و برنامه |

## مسیرها

| مسیر | کاربرد |
|---|---|
| `/opt/bkup` | پوشهٔ برنامه |
| `/opt/bkup/.env` | پورت، آدرس دیتابیس، پوشهٔ بکاپ و منطقهٔ زمانی |
| `/opt/bkup/db/custom.db` | دیتابیس تنظیمات |
| `/opt/bkup/backups` | نسخه‌های محلی بکاپ‌ها |
| `bkup` | دستور منوی ترمینال |
| `bkup.service` | یونیت systemd |
