## معرفی

ابزار `bkup` یک سرویس قدرتمند و سبک مبتنی بر **systemd** است که برای تهیه‌ی خودکار و کامل بکاپ‌های دقیق از پنل‌ها طراحی شده است. این سرویس به‌صورت امن به پنل‌های تنظیم‌شده متصل می‌شود، در زمان‌بندی دلخواه بکاپ از پنل‌های متصل شده میگیرد و فایل‌های بکاپ را مستقیماً به چت یا کانال تلگرام شما ارسال می‌کند.

هر پنل به‌صورت جداگانه متصل می‌شود؛ کافی است پنل‌هایی را که استفاده می‌کنید فعال کنید و اتصال هرکدام را تنها با یک کلیک بررسی و تست کنید. فاصله‌ی زمانی تهیه‌ی بکاپ نیز بر اساس **ثانیه** قابل تنظیم است.

## امکانات

 - **مدیریت متمرکز:** کنترل و مدیریت پنل‌های 3x-ui، HM Panel، PasarGuard و Rebecca از طریق یک داشبورد.
 - **ارسال به تلگرام:** فایل‌های بکاپ مستقیماً به مقصد تلگرامی شما ارسال می‌شوند.
 - **زمان‌بندی دلخواه:** فاصله‌ی زمانی بکاپ‌ها را بر اساس ثانیه و متناسب با نیاز خود تنظیم کنید.
 - **پنل وب:** مشاهده‌ی لحظه‌ای لاگ‌ها، تاریخچه‌ی بکاپ‌ها، ریستور بکاپ‌ها، ری اسمبل بکاپ‌ها.

## نصب

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/AliRezaC-xrol/bkup/main/install.sh)
```
اگر Node.js 20 روی سیستم نصب نباشد، دستور ابتدا آن را نصب می‌کند، سپس آخرین نسخه‌ی منتشرشده را دانلود و صحت آن را بررسی می‌کند، برنامه را build کرده و سرویس را راه‌اندازی می‌کند. در پایان نیز آدرس پنل و رمز عبور را نمایش می‌دهد.

## شروع سریع

| مرحله | کجا | چه کار |
|---|---|---|
| **۱** | نصب‌کننده | انتخاب پورت (یا پورت تصادفی) و رمز پنل |
| **۲** | مرورگر | باز کردن `http://<server-ip>:<port>` و ورود با رمز |
| **۳** | **Settings** | وصل کردن 3x-ui / HM Panel / PasarGuard / Rebecca و زدن دکمهٔ تست |
| **۴** | **Settings** | وارد کردن توکن بات تلگرام و آیدی چت و زدن دکمهٔ تست |
| **۵** | **Settings** | تعیین فاصلهٔ بکاپ و روشن کردن **Auto backup** |

## آپدیت

| از کجا | چطور |
|---|---|
| پنل وب | **System → Check for updates → Update** |
| ترمینال | `bkup` → **Update** |
| هر جا | اجرای مجدد دستور نصب |

نسخه‌ای که در پنل نمایش داده می‌شود، هنگام Build مستقیماً از کد پروژه گرفته می‌شود؛ بنابراین پس از هر به‌روزرسانی، نسخه‌ی نمایش‌داده‌شده همیشه با نسخه‌ای که واقعاً در حال اجراست مطابقت دارد
## بازسازی پارت‌های بکاپ

بکاپ‌های بزرگ‌تر از **۵۰ مگابایت** پیش از ارسال به تلگرام، به چند بخش شماره‌گذاری‌شده تقسیم می‌شوند.

در بخش **Reassemble** می‌توانید این بخش‌ها را دوباره به فایل اصلی بکاپ تبدیل کنید، بخش‌ها به‌صورت خودکار مرتب شده و **بایت‌به‌بایت** با یکدیگر ادغام می‌شوند، در حالی که فایل‌های اصلی بدون هیچ تغییری باقی می‌مانند، پس از ادغام نیز فایل نهایی از نظر یکپارچگی و صحت داده‌ها بررسی می‌شود.
نوع پنل هر بکاپ نیز به‌صورت خودکار شناسایی می‌شود.

## ریستور بکاپ روی سرور 

بخش **Restore** امکان بازگردانی مستقیم بکاپ روی یک سرور از طریق **SSH** را فراهم می‌کند.

**بازگردانی کامل:** تمام اطلاعات موجود در بکاپ بدون تغییر بازگردانی می‌شوند.
**نصب خودکار:** اگر پنل موردنظر روی سرور نصب نباشد، ابتدا نصب شده و سپس بکاپ روی آن بازگردانی می‌شود.
**تاریخچه Restore:** نتیجه، وضعیت و خطاهای هر عملیات Restore ثبت می‌شوند و در صورت نیاز، امکان اجرای مجدد آن با یک کلیک وجود دارد.

## منوی ترمینال

روی سرور `bkup` را اجرا کنید:

| گزینه | کاربرد |
|---|---|
| **Status** | وضعیت سرویس، نسخهٔ نصب‌شده، وجود آپدیت |
| **Web panel URL** | نمایش آدرس و پورت پنل |
| **Password** | تغییر رمز پنل وب |
| **Port** | تغییر پورت پنل وب |
| **Logs** | دنبال‌کردن زندهٔ لاگ سرویس |
| **Start panel** | روشن‌کردن سرویس وب‌پنل |
| **Stop panel** | خاموش‌کردن سرویس وب‌پنل |
| **Restart panel** | ری‌استارت سرویس وب‌پنل |
| **Update** | نصب آخرین نسخه درجا، با حفظ دیتا |
| **Uninstall** | حذف سرویس و برنامه |

## مسیرهای سرور

| مسیر / دستور | کاربرد |
|---|---|
| `/opt/bkup` | پوشهٔ برنامه |
| `/opt/bkup/.env` | پورت و مسیرها |
| `/opt/bkup/db/custom.db` | دیتابیس تنظیمات |
| `/opt/bkup/backups` | نسخهٔ محلی بکاپ‌ها |
| `bkup` | دستور منوی ترمینال |
| `bkup.service` | سرویس systemd |
